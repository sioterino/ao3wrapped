## Installation

To run `ao3wrapped`, you need to install the required Python dependencies.

### Install Dependencies

You can install the necessary Python dependencies using the `dependencies.txt` file. Here are the instructions for different operating systems.

#### On Linux/macOS

1. Ensure you have Python 3 and `pip` installed. You can check by running:

   ```bash
   python3 --version
   pip3 --version
   ```

2. Install the dependencies:

   ```bash
   pip3 install -r dependencies.txt
   ```

#### On Windows

1. Ensure you have Python 3 and `pip` installed. You can check by running:

   ```cmd
   python --version
   pip --version
   ```

2. Install the dependencies:

   ```cmd
   pip install -r dependencies.txt
   ```

## Running the Program

### On Linux/macOS

1. Navigate to the folder where the `ao3wrapped.py` script is located.

2. Run the script using Python 3:

   ```bash
   python3 ao3wrapped.py
   ```

### On Windows

1. Navigate to the folder where the `ao3wrapped.py` script is located.

2. Run the script using Python:

   ```cmd
   python ao3wrapped.py
   ```
